# bank-churn-roi-optimization
Ce projet vise à prédire le départ des clients (*churn*) d'une établissement bancaire à partir d'un jeu de données de 10 000 clients.  L'objectif central n'est pas uniquement la performance technique du modèle, mais **l'impact financier réel (ROI)** généré par une campagne de rétention ciblée.
